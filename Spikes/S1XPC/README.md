# S1 私有 XPC 复测

在当前图形登录会话运行 `python3 Spikes/S1XPC/run.py`。每次在本轮证据目录下建立新 UUID 子目录。A、B、负对照都用 LaunchServices 启动，应用外壳只在该子目录内轮换。需要原有的 DabaiPet Local Dev 签名身份。签名时若系统询问使用私钥，属于构建阶段。

预先约定以下失败条件。

- 主程序 DR 或证书变化、主程序 CDHash 相同、包内服务内容或签名不同，均停止运行。
- 签名检查失败的客户端必须得到明确的身份拒绝，且服务在处理该请求期间没有进入钥匙串操作。连接丢失或没有响应不能算负对照通过。
- A 没有成功新增、A 或服务仍在运行、B 没有冷启动、B 免交互读取失败、摘要不一致，均不能证明跨重建可读。
- 清理只针对本轮成功新增的 UUID，并校验创建摘要。删除或随后查无此项缺少回执时，不能报通过。

服务协议只接受操作名。标识、证书、账号、命名空间和服务回执位置都编译进本轮产物。随机值只在服务进程和钥匙串内出现，宿主只获得摘要。成功仅覆盖固定服务产物和本轮环境。
